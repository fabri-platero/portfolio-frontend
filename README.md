# Fabrizio Platero — Portfolio

Personal portfolio built as a single-page site with smooth scroll-snap sections, dark/light
mode, and a scroll-aware navbar.

## Stack

- [React 19](https://react.dev)
- [Vite 8](https://vite.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- [react-icons](https://react-icons.github.io/react-icons)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it.

## Build

```bash
npm run build
npm run preview
```
